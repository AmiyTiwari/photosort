PhotoSort

All photos

Import photos

Originals are never modified or deleted. Each unique photo is stored once; every original path is remembered as a source of it. Re-importing the same folder only processes new or changed files.

    Imports

    Near-duplicates

    Exact copies are already merged automatically. These groups are the same picture re-saved at a different size/quality (variant) or shots taken seconds apart (burst). ★ marks the copy that is kept visible; click another photo to choose it instead.

    Export folder views

    Creates a folder tree such as Date/2025/December 2025/… where every file is a hardlink to the single stored copy, so a photo can appear in many folders without using more disk space.

    People

    Face detection is off. Run .venv/bin/python -m photosort models, then Settings → Re-analyse library.

    Review queue

    The questions that sort the most photos per answer come first. Skipped questions are not asked again.

    Settings

    Assistant model

    Use any provider: OpenAI, Google Gemini, Anthropic, OpenRouter, or a model on your own machine (Ollama, LM Studio, or any OpenAI-compatible server). The model must support tool/function calling. The API key is stored only on this computer, in library/secrets.json, readable only by you.

    Runs the claude command installed on this computer with the model it is set to (leave Model id empty for that) — nothing else to configure.

    Sorting

    Content groups

    Sorted by what is in the photo, using a local image-understanding model (CLIP). Describe the group in a few short phrases. Answering "which of these belong?" in Review teaches it.

    Custom groups

    Rules are re-applied to every new import. The assistant can create these from plain language.
